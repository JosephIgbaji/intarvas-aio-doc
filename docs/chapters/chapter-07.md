## 🌍 Language Options (Multilingual Support)

INTARVAS AIO offers extensive language support to fully adapt to multilingual working environments. This allows each user to increase their productivity by using the platform in the language they are most proficient in.

## 🛠 Language Options Offered

The platform contains many options, including the following languages:

- 🇹🇷 Turkish
- 🇬🇧 English
- 🇩🇪 German
- And many other language options...

## 💡 Usage Advantages

- **Personalization**: Each user can independently change the interface language through their own profile settings.
- **Global Operation**: Your teams in different countries can work synchronously in their own languages on the same system.
- **Decrease in Error Rate**: Having terms and commands in the native language minimizes the risk of making incorrect operations.

::: tip Professional Recommendation
When you change the language, not only menu headings but also system alerts and notifications are automatically adapted to the language you choose.
:::
