# Chapter 15: 📞 Caller ID and Line Information

  <img src="/images/intarvas IMGs/Communication-Channel.png" alt="Caller ID and Communication Channel Routing" />
  <div class="doc-img-caption">Visual Reference: Caller ID and Communication Channel Routing</div>

When you start a call or receive a call via the search screen (Softphone), the following three critical information are located at the top of the screen:

## 🛠 Information Displayed

- **Number you are looking for**: The phone number of the customer or person you are currently communicating with.
- **Number You Searched**: Your outgoing number (DID), which is de fi ned in the system and appears on the other party's screen. If you have multiple numbers, you can verify which line you are talking on here.
- **Your Internal Number**: A short number assigned to you within the system (Example: 1002). This information identi fi es you during intra-team transfers or domestic calls.

## 💡 Why is it Important?

- **Correct Representation**: Knowing which number you are calling allows you to address the customer with the correct corporate identity.
- **Quick Action**: You can use this information when transferring a call to another friend or asking for help from the internal line.
- **Security and Control**: It helps you monitor in real time which lines the search traf fi c is passing through.

::: tip Professional Recommendation
If you have different extension numbers for different departments (Sales, Support, etc.), make sure you are calling with the correct identity by checking the "Number You Are Calling From" information before starting the call.
:::
