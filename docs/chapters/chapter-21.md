# Chapter 21: 🔗 Person Card Merging Feature

It allows you to collect multiple registrations belonging to the same real person but opened at different times or with different contact information (different phone or email) in a single profile.

## 🛠 Why Should You Merge?

- **Single View of Customer**: It allows you to see all the customer's past correspondence, requests and notes not divided into different cards, but in a single timeline.
- **Data Cleaning**: By preventing the system from having 2-3 of the same person, it helps the guide stay current and regular.
- **Correct Reporting**: It prevents data fragmentation when analyzing how many times a customer has called or how long it takes to reach a solution.

## 🔄 How to Apply?

When you notice that a new registration has been opened with a different contact information belonging to the same person (for example, an old email or a second phone line):

- **Matching**: You can use the "Combine" command by selecting two records.
- **Data Transfer**: All contact information and past conversations on the second card are automatically transferred to the main card.
- **Single Profile**: At the end of the transaction, there is only one "Main Person Card" left in the system and all information is consolidated on this card.

::: tip Professional Advice
Since the merging process is irreversible, it is important for data security to ensure that the first name, last name and contact information are truly the same person before merging the cards.
:::
