Save is the button that allows information updates such as name, phone number, email or company on your personal card to be processed instantly by the system.

## 🛠 The Difference Between "Save" and "Save and Close"

These two processes should not be confused, because both have different purposes:

- **Save**: It updates the data while the conversation is still ongoing or while working on the person card. It does not close the card, it only writes the current changes to the database.
- **Save and Close**: It noti fi es the system that the transaction is completely completed, finalizes the result code and removes the card from the screen.

## 💡 Why is it Important?

- **Prevents Data Loss**: By recording the notes you take or the numbers you update during a long meeting instantly, you prevent data loss in case of a possible connection loss.
- **Live Update**: As soon as you save the information, another team member can access the most up-to-date data when they query the same person.
- **Flexibility**: It is used to make sure you are comfortable with all the other changes you have made, if you are not yet ready to close the card (for example, if you are still waiting for a file).

::: tip Professional Tip
Especially in complex files where you enter a lot of information, use the "Save" button as a checkpoint. This way, you can ensure that your data is safe before saying "Save and Close" at the end of the process.
:::
