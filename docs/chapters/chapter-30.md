Tracking Request is the inclusion of issues that cannot be resolved during a meeting with the customer or require a specific process (e.g., Return request, Fault record, Information request) into the work flow by being recorded.

## 🛠 What Can Be Done with the Request Module?

- **Creating a Request**: You can open a new support request (ticket) associated with the person at the moment of the conversation or after it.
- **Status Control**: You can instantly track which stage the created request is in (New, In Process, Pending, Solved, etc.).
- **Process Tracking**: You can see in chronological order who is on top of the request, how long it has been waiting and the updates made.
- **Customer Information**: As the request status changes (e.g., "Your request has been resolved"), automatic notifications can be triggered through the system.

## 💡 Why is it Important?

- **Accountability**: Prevents the loss of the customer's request in the system; each request has a owner and a deadline.
- **Efficiency**: It facilitates the transfer and tracking of complex problems to different departments (e.g. Accounting, Technical Team) based on "requests".
- **Customer Satisfaction**: When the customer calls back, it allows you to provide concrete information such as "Your request is currently in the review stage, we will get back to you as soon as possible."

::: tip Professional Advice
If the issue is not resolved immediately after a meeting, be sure to create a Request. This way, you can both track your work and your other team members can see the current process regarding that person.
:::
