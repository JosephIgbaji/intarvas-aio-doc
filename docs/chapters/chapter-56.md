Access URL; https://app.intarvas.com/contacts The Filtering Module is an intelligent filter that instantly presents you with segments that match the criteria you are looking for (e.g., "VIP Customers in Ankara" or "Those who have not been searched in the last 3 months") instead of digging a hole with a needle in your customer database.

## 🛠 Functional Features

- **Multiple Criteria Selection**: You can filter dozens of different data such as name, surname, email, phone, city, tag or user-based private areas at the same time.
- **Save Filter**: You can save it by giving a name to the set of criteria you specify (e.g., "Potential Sales List"), and you can access this filter with one click later.
- **Filter Cleaning**: You can return to the main list as quickly as possible by resetting all criteria with a single button.
- **Dynamic Update**: The filter you have saved automatically includes people who have been newly added to the list and meet the criteria; it does not require manual updating.

## 💡 Why is it Important?

- **Focus**: It allows the representative to focus only on a specific region or campaign group instead of making random calls.
- **Time Saving**: You do not waste time by choosing the same 5-6 criteria every time, thanks to the saved filters, you start the operation in seconds.
- **Reduce Error Rate**: Thanks to standardized filters, you can ensure that the entire team works on the same correct data set.

Save the filters you use frequently (e.g., "Things to Follow Today") and open your list with this saved query every morning. When you're done, refresh your screen for the next task using the "Clear" button. Registered Filters is an intelligent library that stores the complex search criteria you have created before under a single name and allows you to apply them to the entire dataset in seconds whenever you need them.
:::

## 🛠 Functional Features and Usage

- **Filter Viewing**: You can see all the special queries you have previously saved (e.g., "Pending Payments", "VIP Istanbul", "Campaign-1 Group") in a list.
- **Quick Application**: As soon as you click on the filter you choose from the list, the system scans the entire database and only presents you with people who meet those criteria.
- **Dynamic Update**: A registered filter is not static. For example, if you have a filter named "Today's New Arrivals", it automatically covers new people who have entered the system that day every time you click.

## 💡 Why is it Important?

- **Standard Operation**: Ensures operational consistency by ensuring that all representatives work with the same criteria (e.g., with the same "Potential Customer" filter).
- **Speed and Agility**: Instead of manually selecting 5-10 different criteria every morning, it allows you to get started with just one click.
- **Reset Error Percentage**: Eliminates criterion errors that can occur in manual selections (e.g., incorrect city or label selection).

::: tip Professional Recommendation
Determine the 3 main filters you use most (e.g., Emergency Tracking, New Registrations, Priority Area) and save them. By making your transitions throughout the day through these registered lists, you can increase your focus time by 40%.
:::
