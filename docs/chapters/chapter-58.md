Restrictions and Blacklist Management)

Access URL; https://app.intarvas.com/contacts/blocked Blocked is a security panel where blocked individuals or numbers, whose access to the system is restricted through various channels (Phone, WhatsApp, SMS, etc.), are listed and managed centrally.

## 🛠 Functional Features

- **Central List**: You can see all contacts that have been blocked by any representative or administrator before in chronological order on a single screen.
- **Unblocking (Whitelist)**: You can make a contact that was mistakenly blocked or decided to be unblocked again "Active" with a single click and allow it to communicate with the system.
- **Channel-Based View**: You can monitor operational security by tracking which number or ID was blocked on which date.

## 💡 Why is it Important?

- **Preventing Productivity Loss**: It prevents unnecessary, spam or harassing calls/messages from being queued, allowing representatives to focus on real customers.
- **Operational Hygiene**: It offers a cleaner dataset by preventing your CRM database from being filled with spam records.
- **Control and Monitoring**: Tracking blocked users allows you to analyze which external sources the system is being attacked or abused from.

::: tip Professional Recommendation
Before blocking the number, be sure to check the "Call History". If the number was blocked by mistake, you can immediately bring the customer back to the system by saying "Remove Block" from the "Blocked" menu.
:::
