### 📊 Data List (Smart Column Matching and

Data Package Management)
The Data List Module is the "Data Architect" area where you manage the bulk data
packages loaded into the system and configure the data by matching Excel column
headers with INTARVAS AIO CRM fields (First Name, Last Name, Phone, Company, etc.).

### 🛠 Data Configuration and Matching Steps

<div class="doc-img-container">
  <img src="/images/mohammed/section-60_-data-configuration-and-matching-steps.png" alt="Data Configuration and Matching Steps" />
  
</div>

### 💡 Why is it Important?

- **Data Package Tracking**: It allows you to see the packages created after "Data Upload" in bulk and track their upload status.
- **Smart Column Matching (Data Mapping)**: You match the column headers in the file you upload (e.g., "Customer No", "GSM", "City") with their corresponding values in INTARVAS AIO CRM. This step allows the system to learn which data to store in which cell.
- **Operations Area**: Through the operations menu specially provided for each data package; you can match, filter out erroneous records or transfer matched data to the live CRM database.
- **Visual Verification**: The system offers a visual matching interface to minimize user errors; thus, it clearly verifies which Excel column is transferred to which CRM field.
- **Flexible Data Structure**: Regardless of the format of your Excel file, you can adapt the file to the system without corrupting it thanks to INTARVAS AIO's flexible matching engine.

::: tip Professional Tip
Professional Tip: When matching the "Data List" match, try to keep the column
headers in your Excel file similar to the field names in INTARVAS AIO CRM (e.g., "Phone" instead of "Tel"); the system will automatically detect these similarities
and reduce your matching time by 80%. After the match is complete, check the
first few rows to ensure that the data is placed in the correct cells.
